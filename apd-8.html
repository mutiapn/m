B. Pseudocode (Kode Semu)

Aturan Operator & Lab Pertukaran Variabel (Swap)

Pseudocode menulis algoritma menyerupai bahasa pemrograman, tetapi tetap mudah dibaca manusia.

📌 Penugasan (<- atau =)

Mengisi suatu nilai ke dalam wadah/variabel. Contoh: suhu <- 37.

🧮 Operator Matematika

+ (tambah), - (kurang), * (kali), / (bagi), dan mod (sisa hasil bagi).

🧪 Uji Coba Operator mod (Sisa Bagi)
mod = 1

7 dibagi 2 hasilnya 3, sisa 1. (Coba ganti angka 7 menjadi 8!).

A. Percabangan (IF - ELSE IF - ELSE)

Simulator Lampu Lalu Lintas & Reaksi Kendaraan

Prinsip kerja: Program mengecek kondisi dari atas ke bawah. Jika menemukan kondisi yang BENAR (True), perintah di dalamnya dijalankan, lalu kondisi di bawahnya langsung diabaikan.

Klik Warna Lampu Lalu Lintas:
SIMULASI AKSI KENDARAAN HATI-HATI
🚗
GARIS
INPUT warna = "Kuning"
IF warna == "Merah" THEN
aksi = "BERHENTI"
ELSE IF warna == "Kuning" THEN
aksi = "HATI-HATI"
ELSE
aksi = "JALAN"
ENDIF
PRINT aksi → "HATI-HATI"

    Bab 4 • Analisis Kecepatan Komputasi

    Arena Balap Efisiensi: Searching & Sorting

    ✓ Misi Bab 4 Selesai (+100 XP)
    🔎 Algoritma Pencarian (Searching)

    Untuk mencari nilai tertinggi atau terendah dari data yang acak, metode memeriksa satu per satu dari awal hingga akhir (Linear Search) jauh lebih efektif dibandingkan mengurutkan seluruh data terlebih dahulu, karena jumlah langkah komputasinya jauh lebih sedikit.

    📊 Algoritma Pengurutan (Sorting)
    • • Selection Sort: Mencari data terkecil/terbesar lalu menukarnya langsung ke posisi yang benar (lebih hemat swap).
    • • Bubble Sort: Membandingkan dan menukar dua data bersebelahan secara berulang-ulang.
    💡
    Catatan Penting: Jika jumlah data sangat sedikit (misalnya hanya 8 sampai 10 data), perbedaan kecepatan kedua algoritma pengurutan ini hampir tidak terasa.
